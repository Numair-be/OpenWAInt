Publish with GitHub Desktop
===========================
1. File → Add local repository
2. Choose: C:\Users\Numair\Desktop\share\OpenWAInt
3. Commit all changes → Publish / Push to https://github.com/Numair-be/OpenWAInt.git

On the server (WSL, /mnt/c/WhatsappAPI/relay):
  git pull
  cp .env.example .env
  cp lists.example.json lists.json
  # Optional server networking: see docker-compose.override.example.yml
  docker compose up -d --build

OpenWA (separate clone, not this repo):
  git clone https://github.com/rmyndharis/OpenWA.git /mnt/c/WhatsappAPI/openwa
  cp scripts/openwa-docker-network.override.example.yml ../openwa/docker-compose.override.yml

Boot on Windows server (Docker inside WSL): README.md § "Start on server boot"

Do not commit: .env, lists.json, node_modules/
