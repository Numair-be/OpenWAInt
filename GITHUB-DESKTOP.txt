Publish with GitHub Desktop
===========================
1. File → Add local repository
2. Choose this folder: C:\Users\Numair\Desktop\share\OpenWAInt
3. If asked to create a repo here, choose "create a repository"
4. Repository → Publish repository (pick name, e.g. openwa-whatsapp-relay)

After clone on a new machine:
  copy .env.example .env
  copy lists.example.json lists.json
  (edit both — never commit real .env or lists.json)

  OpenWA is separate: clone https://github.com/rmyndharis/OpenWA.git
  docker compose -f docker-compose.dev.yml up -d   # in OpenWA folder
  docker compose up -d --build                     # in this relay folder

  npm run demo:alert   # optional test UI on :3100

Do not commit: .env, lists.json, OpenWA/, node_modules/
